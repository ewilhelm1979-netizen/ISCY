# ISCY V23.7.33 publication marker

This repository marker intentionally triggers the guarded `Publish ISCY V23.7.33` workflow only after the release pull request is merged to `main`.

The workflow must fail closed unless the root release manifest is `prepared_not_published`, all release metadata checks pass, the portable binary is reproducible across two builds, the six-file bundle validates, and neither the `V23.7.33` tag nor GitHub Release already exists.
